# Codex Field Guide

A dark-first, navigable field manual for learning to work with Codex as an engineering partner.

The published site is served from this repository with GitHub Pages. Open `index.html` locally for a static preview, or use the repository's Pages URL after the deployment workflow completes.

## Included interactions

- URL-addressable guide windows for the control room, engineering loop, glossary, work orders, and verification checklist.
- Dark mode by default with a persistent light-mode toggle.
- Responsive navigation drawer for small screens.
- Searchable glossary, copyable work-order templates, and a quick-start dialog.
