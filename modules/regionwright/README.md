# Regionwright: Studio

Regionwright: Studio is the visual Region authoring and scenario workspace for Foundry VTT. It owns native Region behavior setup, map-first selection, Studio activities, story progression, Scene portals, traps, and the current Regionwright campaign integrations.

## Other Regionwright modules

- **Regionwright: Puzzles & Locks** (`regionwright-puzzles-locks`) is an independent optional module for Tumbler Lock, Rotation Lock, Mirror Redirect, Timing Dial, Ingredient Mixing, Spine Mosaic, and the Puzzle HUD.
- **Regionwright: Hunting & Gathering** (`regionwright-hunting-gathering`) is an independent optional module for Hunting, Fishing, Mining, resource catalogs, and item packs.

Studio does not require either module. Existing Regionwright settings and saved Scene data stay in the `regionwright` namespace.

Designed for Foundry VTT v14. DialogV2 and native Foundry form styles provide window surfaces and controls; Regionwright CSS handles layout, visual map feedback, and scenario artwork.
