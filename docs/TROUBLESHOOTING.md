# Troubleshooting

## The item I selected is not obvious on the map

Choose the item again from the list. Regionwright moves the pulsing locator beacon to the current selection. If the item is on another Scene, switch to the Scene named in the prompt before choosing it.

## A player cannot finish a lock

Check that an active Game Master is connected. Players can solve the puzzle, but the Game Master performs the final Door update.

## I cannot add a Region effect, puzzle, or trap

Open Foundry’s Configure Settings and make sure the appropriate Regionwright write setting is enabled. Only a Game Master can enable these settings.

## An option is missing

Some Region Behaviors come from Foundry or the active game system. Regionwright hides options that are not available in the current world.

## A cross-Scene step will not continue

Read the Scene name in the prompt, switch to that Scene, then select the requested item. Regionwright keeps the selection tied to the correct Scene.
