# Permissions

## Game Master setup

Only a Game Master can create or change Regionwright setups. Regionwright asks for confirmation before it changes a Region, Door, or related setting.

## Player puzzle play

Players do not need permission to edit Doors to use a Regionwright lock. A player’s successful puzzle action is sent to the active Game Master, who performs the Door update. This keeps Door ownership and world changes under GM control.

If no active Game Master is connected, a player cannot complete an action that changes the world. The puzzle explains that the GM needs to be online.

## Write settings

Regionwright keeps world-changing actions off until a Game Master enables the relevant setting in Foundry’s Configure Settings screen. Enable Region writes for Region Behaviors and Puzzle writes for puzzles or traps.
