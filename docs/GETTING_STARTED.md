# Getting Started with Regionwright

Install the modules you want in Foundry's Add-on Modules area. They have separate module IDs and can be enabled together.

- **Studio** provides visual Region authoring, native behavior setup, Studio activities, traps, and its campaign integrations. See [the Studio guide](../modules/regionwright/README.md).
- **Puzzles & Locks** provides the lock and puzzle setup hub and Puzzle HUD. See [the Puzzles & Locks guide](../modules/regionwright-puzzles-locks/README.md).
- **Hunting & Gathering** provides Hunting, Fishing, Mining, catalogs, and item packs. See [the Hunting & Gathering guide](../modules/regionwright-hunting-gathering/README.md).

Each module owns its settings and runtime. Enable only the module features you want. Optional Studio integrations do not make Puzzles & Locks or Hunting & Gathering required dependencies.

For saved-data migrations, back up the world first, launch it as the active GM, and review the module log for migration results. Do not edit Foundry's database files directly.
